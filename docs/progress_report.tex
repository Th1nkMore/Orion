\begin{abstract}
本报告总结 UQ-ORION 项目的当前进展。该项目在 ORION（ICCV 2025）端到端自动驾驶框架的基础上，通过轻量不确定性量化（UQ）模块和 FiLM 条件调制机制，提升模型在恶劣天气场景（雨、雾、夜间）下的安全性。

截至目前，我们已完成 UQEstimator 训练（AUROC=0.954）、FiLM 双层注入、碰撞感知训练、以及 50 场景闭环评估。实验表明恶劣天气下碰撞率降低 21\%--23\%，但存在正常场景轨迹退化问题（ADE +116\%），已定位根因（FiLM 调制的空间盲目性与 LayerNorm 范数崩塌）。

在此基础上，我们完成了 Phase $-$1 可行性验证（5 项中 4 项已确认），发现了若干关键的计划假设偏差：BEV query 并非 $30 \times 30$ 规则网格而是 600 + 300 个 learned embedding；\texttt{poses\_cls} 采用 sigmoid focal loss（非 softmax）；Flash Attention 阻断 attention weights 提取但有明确缓解方案。本报告据此修正技术路线，提出以 k-NN 空间插值替代双线性采样、以乘法门控替代 logit 减法的 BEV 不确定性代价注入方案。
\end{abstract}

\section{研究背景与动机}

\subsection{问题定义}

ORION 是一个基于 VLM（Vision-Language Model）的端到端自动驾驶框架，在标准场景下表现优秀。其核心流程为：
\begin{center}
    Vision Encoder $\to$ QT-Former $\to$ VLM $\to$ Planning Token $\to$ VAE $\to$ 轨迹
\end{center}

然而，VLM-based planner 存在一个关键缺陷：\textbf{在恶劣天气（雨、雾、夜间）等 OOD 场景下过度自信}，无法感知自身感知质量的下降，从而做出激进的轨迹决策。

通过对 Bench2Drive 验证集（12,806 个样本）的分析，我们发现了一个令人警醒的统计事实：

\begin{insightbox}[核心发现：恶劣天气碰撞率放大效应]
\begin{itemize}[leftmargin=1.5em]
    \item 恶劣天气碰撞率是正常天气的 \textbf{161 倍}（1.61\% vs 0.01\%）
    \item 但恶劣天气的 L2 轨迹误差反而\textbf{低于}正常天气（1.78m vs 2.38m）
    \item 模型「看起来精度不错」但实际碰撞风险剧增
\end{itemize}
\end{insightbox}

这一发现揭示了传统开环 L2 评估指标的局限性——轨迹精度与安全性是两个不同维度的概念。

\subsection{研究目标}

在不微调 ORION 主干（${\sim}1$B 参数，36GB 模型文件）的前提下，设计一个轻量即插即用的不确定性感知安全扩展方案：
\begin{enumerate}[leftmargin=2em]
    \item \textbf{量化感知不确定性}：训练轻量 UQ 估计器，从视觉 token 提取每帧的不确定性分数与嵌入
    \item \textbf{空间化不确定性}：将不确定性从全局标量升维为 BEV 空间热力图，使规划器感知"哪个区域的感知不可靠"
    \item \textbf{约束轨迹决策}：用不确定性代价约束多模态轨迹模式选择，主动规避感知可靠性低的区域
\end{enumerate}

约束条件：新增参数 $<$ 5M，零主干微调，轻量侧信道注入（在冻结层的激活值上施加 FiLM 调制，适用于任意冻结的端到端驾驶模型）。

\subsection{UQEstimator 模型}

UQEstimator 接收 EVAViT 的 patch tokens 和 5 维统计特征，输出不确定性 score $\in [0,1]$ 和 256 维 embedding。

\textbf{模型结构}：
\begin{itemize}[leftmargin=2em]
    \item \textbf{Patch 投影}：Linear($1024 \to 256$)，降维控制参数量
    \item \textbf{Cross-Attention 池化}：2 层 TransformerDecoder，16 个 learnable queries 通过 cross-attention 自适应关注最相关的 patches
    \item \textbf{统计特征分支}：5 维原始特征 $\to$ Linear($5 \to 64$) + GELU + LayerNorm
    \item \textbf{融合}：concat $[256 + 64] \to 512 \to 256$
    \item \textbf{输出头}：score\_head (Sigmoid $\to [0,1]$)，embed\_head (LayerNorm $\to$ FiLM 条件向量)
\end{itemize}

总参数量：2,210,817（2.21M），远在 5M 预算之内。

\subsection{FiLM 双层注入}

FiLM（Feature-wise Linear Modulation）通过 $\text{output} = \gamma \odot \text{input} + \beta$ 实现条件调制：

\begin{itemize}[leftmargin=2em]
    \item \textbf{FiLM L1}（QT-Former 层，0.13M）：调制检测 query，让下游 LLM 接收到``视野受限''的场景表示
    \item \textbf{FiLM L2}（VAE 层，2.11M）：调制 ego\_feature（规划 token），将轨迹分布向保守模式偏移
\end{itemize}

两层 FiLM 均采用 Identity 初始化（$\gamma = 1, \beta = 0$），确保新增模块不破坏原有性能。

\subsection{当前 FiLM 方案的根本局限}
\label{sec:limitation}

在第一阶段的实验结果中，Normal 场景 ADE 退化 +116\% 揭示了当前方案的两个结构性缺陷：

\textbf{缺陷一：空间盲目性。} UQEstimator 通过 mean-pool 将 $6 \times 1600$ 个 patch 的 cross-attention 权重压缩为 256 维全局向量，空间信息完全丢失。FiLM 对所有 BEV query 施加相同调制，无法区分"前方不确定"与"侧方不确定"。

\textbf{缺陷二：LayerNorm 范数崩塌。} \texttt{embed\_head} 末尾的 LayerNorm 使所有样本的 embedding $\ell_2$-norm 恒定（$\approx \sqrt{256}$）。因此，FiLM 的调制强度不随 UQ score 变化，Normal 场景（score $\approx 0$）也受到等幅调制。

这两个缺陷相互叠加，导致现有 FiLM 方案的本质是``全局风格迁移''而非``空间感知的安全规划''。后续工作针对这两点分别设计修复方案（见第~\ref{sec:nextsteps}节）。

\subsection{伪标签设计的自洽性}

伪标签基于 patch token 统计特征（max\_mean/cosim/entropy）计算，UQEstimator 也以相同特征为输入，二者存在\textbf{部分特征重用}。但以下三点保证了结论的自洽性：
\begin{enumerate}[leftmargin=2em]
    \item \textbf{结构学习独立于规则}：UQEstimator 新增 2 层 TransformerDecoder（16 个 learnable queries，cross-attention），学到统计规则之外的空间结构信息；伪标签为手工加权组合，模型为学习映射，并非同一函数
    \item \textbf{外部验证独立}：AUROC=0.954 使用 weather-based scene\_type 分类（天气 ID 0-3），该分类完全独立于伪标签生成中使用的统计权重——AUROC 是对天气感知能力的独立验证，而非循环验证
    \item \textbf{迭代进步可追溯}：v1→v3 的 AUROC 迭代（0.621→0.601→0.954）中，v3 改进主要来源于 scene\_type 分类修正（19.4\% 样本重新对齐），而非统计特征过拟合
\end{enumerate}

\subsection{损失函数设计}

\textbf{UQEstimator 训练}：
\begin{equation}
    \mathcal{L}_{\text{UQ}} = \mathcal{L}_{\text{MSE}} + 0.1 \cdot \mathcal{L}_{\text{cal}} + 0.5 \cdot \mathcal{L}_{\text{rank}}
\end{equation}
其中 $\mathcal{L}_{\text{cal}}$ 为校准正则项（惩罚 score 标准差过小），$\mathcal{L}_{\text{rank}}$ 为 pairwise margin ranking loss。

\textbf{FiLM 碰撞感知训练}：
\begin{equation}
    \mathcal{L}_{\text{FiLM}} = \mathcal{L}_{\text{plan}} + \lambda_{\text{col}} \cdot \mathcal{L}_{\text{col}}
\end{equation}
其中碰撞 loss 为 UQ score 加权的 hinge margin loss：
\begin{equation}
    \mathcal{L}_{\text{col}} = \mathbb{E}\left[ \text{ReLU}(m - d_{\min}) \cdot s_{\text{UQ}} \right], \quad m = 4.0\text{m}, \quad \lambda_{\text{col}} = 0.5
\end{equation}

\subsubsection{关键修正}

基于 Phase $-$1 发现，以下计划假设被修正：

\begin{enumerate}[leftmargin=2em]
    \item \textbf{BEV query 布局}：原假设 900 个 query 排列在 $30 \times 30$ 规则网格上，实际为 600 main (\texttt{nn.Embedding(600,3)}) + 300 propagated (\texttt{nn.Embedding(300,3)}) 个 learned 位置。\textbf{双线性采样不可用}，改用基于 \texttt{reference\_points} 坐标的 k-NN 空间插值（k=5）。
    \item \textbf{\texttt{poses\_cls} 类型}：原假设为 softmax logits，实际为 sigmoid focal loss 训练的独立 scores。Mode 选择为 \texttt{argmax(poses\_cls)}。\textbf{logit 空间减法不适用}（sigmoid 极端值对减法不敏感），改用乘法门控。
    \item \textbf{attn\_weights shape}：$[B, 900, 9600] \to [B, 600, 9600]$（600 main queries 参与 cross-attention，300 propagated 需 hook 验证）。显存估算从 34MB/sample 降至 23MB/sample。
    \item \textbf{Score-Gated FiLM 改动范围}：原估 2 个文件约 6 行，修正为 3 个文件约 12 行（新增 \texttt{orion\_head.py} 传递 \texttt{uncertainty\_score}）。
\end{enumerate}

\subsubsection{补充发现：UQ Score 高度双峰分布}

对 12,806 帧 eval 数据分析确认 UQ score 呈高度双峰分布（Normal 中位数 $\approx$ 0，Adverse 中位数 $\approx$ 0.97），\textbf{消除了 Score-Gated FiLM 在 Normal 场景仍被调制的风险}——当 $s \to 0$ 时 FiLM 严格退化为恒等变换。

\subsubsection{补充发现：Plan Anchor 空间多样性充分}

对 20 个 plan anchor 的 BEV 走廊 IoU 分析（3m 宽度）：mean IoU = 0.261，88.9\% 的 mode pair IoU $< 0.5$。这证明 BEV uncertainty cost 在不同 mode 上会产生显著不同的值，D 组 vs F 组的对比有意义。建议 cost 计算时对后期时间步（$t \geq 2$）加权，因早期展幅小、区分力弱。

详细报告见 \texttt{results/feasibility/feasibility\_report.md}，可视化见 \texttt{results/feasibility/} 目录。

\section{遇到的问题与解决方案}

\subsection{问题 1：伪标签分类不一致（已解决）}

\begin{issuebox}[严重性：高 \quad 状态：\textcolor{okgreen}{已解决}]
\textbf{现象}：v2 伪标签使用场景类型（Accident$\to$adverse）分类，但 eval\_openloop 使用天气 ID（Weather 0-3=normal）分类。2,481/12,806 样本（19.4\%）分类不一致。

\textbf{影响}：v2 AUROC 0.993 仅在自身标签空间有效，在 eval\_openloop 空间实际仅为 0.601。

\textbf{解决方案}（v3）：引入 weather-based 分类对齐 eval\_openloop，修正后 AUROC 提升至 \textbf{0.954}。
\end{issuebox}

\subsection{问题 2：init\_weights 覆盖 FiLM Identity Init（已修复）}

\begin{issuebox}[严重性：高 \quad 状态：\textcolor{okgreen}{已修复}]
\textbf{现象}：\texttt{PETRTemporalTransformer.init\_weights()} 对所有 Linear 层执行 \texttt{xavier\_uniform\_}，覆盖了 FiLM 层精心设置的 identity 初始化（$\gamma=1, \beta=0$）。

\textbf{影响}：未加载训练权重时 FiLM 不是 identity 而是随机调制。早期 10 场景 baseline 数据不可信。

\textbf{解决方案}：在 \texttt{init\_weights()} 中用参数 ID 排除 FiLM 层。修复后重跑 50 场景 baseline 获得可信对照数据。
\end{issuebox}

\subsection{问题 3：Normal 场景 ADE 严重退化（待解决）}

\begin{issuebox}[严重性：\textcolor{alertred}{关键} \quad 状态：\textcolor{warncolor}{已定位根因，待实现修复}]
\textbf{现象}：Normal 场景 UQ score $\approx$ 0（0.0001--0.0015），FiLM 不应有任何调制效果，但 ADE 从 2.78m $\to$ 6.00m（+116\%）。

\textbf{根因}：\texttt{embed\_head} 末尾的 LayerNorm 使所有样本的 embedding $\ell_2$ norm 恒定（$\approx \sqrt{256} \approx 16$），无论 UQ score 高低。FiLM 计算 $\gamma = W \cdot \text{emb} + b$ 时，由于 embedding norm 恒定，Normal 和 Adverse 场景的调制幅度相当。

\textbf{设计方案}：Score-Gated FiLM（见第~\ref{sec:nextsteps}节）。
\end{issuebox}

\subsection{问题 4b：评估体系约束}

\begin{issuebox}[类型：范围约束 \quad 状态：\textcolor{warncolor}{需论文正面交代}]
本报告所有闭环指标均来自\textbf{回放式闭环评估}（见第~\ref{sec:limitation}节说明）。主要约束：
\begin{enumerate}[leftmargin=2em]
    \item ADE/碰撞改善在真实 CARLA 仿真中的泛化性\textbf{未经验证}
    \item 50 场景碰撞率均值受个别场景影响大（部分 0\%，少数高达 11.25\%）
    \item Normal 场景 ADE 退化（+116\%）尚未修复，Score-Gated checkpoint 待重训
\end{enumerate}
这些约束应在论文中正面交代，并将真实 CARLA 闭环验证作为 Future Work 列出。
\end{issuebox}

\subsection{问题 5：FiLM 的``保守捷径''现象}

\begin{issuebox}[严重性：中 \quad 状态：\textcolor{warncolor}{需第二轮训练解决}]
\textbf{现象}：碰撞感知训练使模型全面趋于保守（Brake MAE +129\%，Throttle MAE +74\%），通过``更慢、更停、更让''降低碰撞率，而非更智能的避障。

\textbf{影响}：ADE 增加 41--80\%。部分场景（CrossingBicycleFlow）甚至因过度制动引入新碰撞。

\textbf{解决方向}：
\begin{enumerate}[leftmargin=2em]
    \item 引入进度/舒适约束，抑制无理由降速
    \item Score-Gated FiLM 实现选择性调制
    \item 对 $\gamma, \beta$ 偏离 identity 加正则约束
\end{enumerate}
\end{issuebox}

\section{后续工作规划}
\label{sec:nextsteps}

\subsection{第一阶段：修复现有方案（1--2 周，本地 16GB 可完成）}

\subsubsection{Score-Gated FiLM 实现与重训}

解决 LayerNorm 范数崩塌问题，将 UQ score 直接作为调制强度的门控信号：
\begin{align}
    \gamma_{\text{raw}} &= W_\gamma \cdot \text{emb} + b_\gamma, \qquad
    \beta_{\text{raw}} = W_\beta \cdot \text{emb} + b_\beta \\
    \gamma &= 1 + s \cdot (\gamma_{\text{raw}} - 1), \qquad
    \beta  = s \cdot \beta_{\text{raw}}
\end{align}

当 $s \to 0$（正常场景）时，$\gamma \to 1, \beta \to 0$，FiLM 退化为恒等变换；当 $s \to 1$（恶劣天气）时，FiLM 满幅调制。

\textbf{代码改动范围}（约 12 行，3 个文件）：
\begin{itemize}[leftmargin=2em]
    \item \texttt{orion\_head.py}：传递 \texttt{uncertainty\_score} 至 transformer（当前仅传 \texttt{uncertainty\_emb}）
    \item \texttt{petr\_transformers.py}：FiLM L1 接收 \texttt{uncertainty\_score}，实现 Score-Gated 公式
    \item \texttt{orion.py}：FiLM L2 同步修改，接收从 \texttt{orion\_head} 返回的新参数
\end{itemize}

\subsubsection{信号有效性验证（Phase 0，无 GPU 需求）}

在开始 BEV 不确定性热力图工作前，先验证 image quality metrics 的有效性：对每帧图像计算三类 per-patch 质量指标——Laplacian variance（边缘清晰度）、梯度幅值（纹理丰富度）、局部对比度（Local Contrast，对雾天对比度下降最敏感），验证恶劣天气帧的质量指标均值显著低于正常天气帧（$p < 0.01$）。

\subsection{第二阶段：BEV 不确定性热力图（核心新贡献，2--4 周）}

\subsubsection{核心思路}

当前 FiLM 方案的空间盲目性源于将 patch 信息压缩为全局向量。受 BEV 感知研究启发，我们提出将 \textbf{patch 级感知质量}通过 QT-Former 的 cross-attention 权重传播至 BEV 空间，构建 \textbf{BEV 不确定性热力图}，并将其作为轨迹模式选择的空间代价。

\subsubsection{计算流程（零额外参数）}

\begin{figure}[H]
\centering
\begin{tcolorbox}[colback=white, colframe=black!50, boxrule=0.3pt, width=\textwidth]
\begin{lstlisting}[basicstyle=\ttfamily\footnotesize, frame=none, backgroundcolor=\color{white}]
Step 1: per-patch quality（从原始图像计算，无需学习）
  patch_quality[j] = f(Laplacian_var[j], grad_mag[j], contrast[j])

Step 2: BEV uncertainty map（通过 QT-Former attention 传播）
  attn_weight[i,j] = QT-Former cross-attention (hook 读取, flash_attn=False)
  bev_uncertainty[i] = sum_j attn_weight[i,j] * (1 - patch_quality[j])
  # 注：BEV query 为 600 main + 300 propagated = 900 个 learned embedding
  # reference_points 为 nn.Embedding(600,3) + nn.Embedding(300,3)，非规则网格

Step 3: per-mode uncertainty cost（k-NN 空间插值，k=5）
  ref_xy = reference_points[:, :2] * 102.4 - 51.2   # learned -> 物理坐标
  uncertainty_cost[m] = mean_t knn_interp(bev_unc, ref_xy, waypoint[m,t], k=5)

Step 4: adjusted mode selection（仅需学 1 个标量 lambda）
  # poses_cls 为 sigmoid scores（非 softmax logits），采用乘法门控
  adjusted_score = poses_cls * (1 - lambda * uq_score * uncertainty_cost)
\end{lstlisting}
\end{tcolorbox}
\caption{BEV 不确定性代价计算流程（修正版）。BEV query 为 learned embedding 而非规则网格，采用 k-NN 空间插值替代双线性采样；\texttt{poses\_cls} 为 sigmoid scores，采用乘法门控替代 logit 减法。\(\lambda\) 为唯一训练参数。}
\end{figure}

\textbf{关键优势}：（1）不需要深度估计或 camera-to-BEV 几何投影；（2）计算 BEV uncertainty map 不需要 LLM 参与，仅需 EVAViT 和 QT-Former（约 0.73GB 显存），可在 16GB 本地设备上完整运行；（3）$\lambda$ 训练可利用离线缓存的特征数据，与 ORION 推理完全解耦。

\textbf{关键修正}（基于 Phase $-$1 验证）：（1）BEV query 为 600 main + 300 propagated 个 learned embedding（\texttt{nn.Embedding}，初始化 $\text{uniform}(0,1)$，训练后学习），并非 $30 \times 30$ 规则网格，因此双线性采样不可行，改用基于 \texttt{reference\_points} 的 k-NN 空间插值（k=5）；（2）\texttt{poses\_cls} 使用 sigmoid focal loss 训练（$\gamma=2, \alpha=0.25$），输出为独立 sigmoid scores 而非 softmax 概率，mode 选择方式为 $\text{argmax}(\texttt{poses\_cls})$——因此不应在 logit 空间做减法（sigmoid 极端值对减法不敏感），改用乘法门控：$\text{adjusted\_score} = \texttt{poses\_cls} \cdot (1 - \lambda \cdot s \cdot c_m)$；（3）Flash Attention 在所有 5 个 transformer 组件中默认开启，阻断 attention weights 提取——缓解方案为提取时临时覆盖 \texttt{flash\_attn=False}，推理速度约降 2$\times$ 但仅影响缓存提取阶段。

\subsubsection{lambda 训练目标}

$\lambda$ 为单一标量参数，训练方式有两种选择：（1）\textbf{网格搜索}（首选）：$\lambda \in \{0.1, 0.3, 0.5, 0.7, 1.0\}$，直接优化离线缓存数据上的 mode 选择命中率（选中 GT 最近 mode 的概率），计算量极小（CPU 秒级）；（2）\textbf{可微训练}：采用 pairwise margin ranking loss 替代 Spearman rank correlation（\texttt{torch.argsort} 无梯度），对每对 mode $(m_i, m_j)$，若 $m_i$ 更安全则鼓励 $\text{adjusted\_score}(m_i) > \text{adjusted\_score}(m_j)$。
\begin{equation}
    \mathcal{L}_\lambda = \sum_{m_i \succ m_j} \max\left(0,\; \text{margin} - (\hat{s}_{m_i} - \hat{s}_{m_j})\right), \quad \hat{s}_m = \texttt{poses\_cls}_m \cdot (1 - \lambda \cdot s \cdot c_m)
\end{equation}
其中安全排序基于各模式与 GT 的 L2 距离构造。注意：原计划中使用的 Spearman $\rho_s$ 不可微（依赖 \texttt{argsort}），已替换为等价的 pairwise ranking formulation。

\subsection{创新点与论文贡献}

\begin{enumerate}[leftmargin=2em]
    \item \textbf{发现}：端到端 VLM 驾驶在恶劣天气下碰撞率放大 161$\times$，但开环 L2 指标无法反映；L2 精度与安全性是两个正交维度
    \item \textbf{方法（第一层）}：轻量 UQ 估计器 + Score-Gated FiLM，通过感知不确定性对 QT-Former 和 VAE 实施条件调制，零主干微调，参数增量仅 4.45M

    \item \textbf{定位}：轻量侧信道注入设计（在冻结层激活值上施加 FiLM 调制），适用于任意冻结的端到端驾驶模型，无需重训骨干网络
    \item \textbf{分析}：系统消融实验（UQ 组件 / FiLM 层级 / 全局 vs 空间不确定性）揭示各模块贡献

\section{总结}

UQ-ORION 项目第一阶段已完成核心验证：UQEstimator 在恶劣天气检测上达到 AUROC=0.954，FiLM 碰撞感知训练在恶劣天气场景降低了 23\% 的碰撞率。当前主要问题是 FiLM 对正常场景的非预期干扰（ADE +116\%），根因已明确为 FiLM 调制的全局性与 LayerNorm 范数崩塌。

Phase $-$1 可行性验证（5 项中 4 项已完成）发现并修正了若干关键计划假设：BEV query 为 600+300 个 learned embedding（非 $30 \times 30$ 网格），须用 k-NN 替代双线性采样；\texttt{poses\_cls} 为 sigmoid scores（非 softmax logits），须用乘法门控替代 logit 减法；同时确认了 plan anchor 空间多样性充分（88.9\% pair IoU $< 0.5$）、UQ score 高度双峰（Score-Gated FiLM 可行）、Flash Attention 有明确缓解方案。

第二阶段以此为切入点，提出修正后的 BEV 不确定性热力图方案，将感知可靠性空间化，直接指导轨迹模式选择。该方案的核心计算链路（EVAViT + QT-Former + 图像统计量）不依赖 LLM，可在现有 16GB 本地设备上完整运行。消融实验扩展至 7 组（新增 G 组：Score-Gated FiLM + Global Penalty），以更严格地验证空间 BEV cost 的独立贡献。需申请 A100 资源的部分（FiLM 重训、大规模闭环评估）预计总 GPU 时间约 103 小时。预计 6--7 周内可完成论文初稿。

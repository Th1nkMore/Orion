# 第二章 方法与工程

## 2.1 整体架构

在 ORION 冻结主干旁增加 **UQEstimator** 与 **双层 FiLM**，数据流如下：

```text
EVAViT (frozen)
  │ patch_tokens [B, 6, 1600, 1024]
  ├──────────────────────────────┐
  │                              ▼
  │                      UQEstimator (2.21M)
  │                        ├─ uncertainty_score [B, 1]  ∈ (0,1)
  │                        └─ uncertainty_embedding [B, 256]
  │                              │
QT-Former (frozen) ◄── FiLM L1 (0.13M) ── score-gated γ, β on queries
  │
Qwen VLM (frozen)
  │ ego / planning features
  ▼
VAE (frozen) ◄── FiLM L2 (2.11M) ── score-gated γ, β on current_states
  │
  ▼
trajectory
```

**设计约束**

| 约束 | 实现 |
|------|------|
| 零主干微调 | 仅训练 UQ + FiLM；推理时 ORION 权重不变 |
| 参数预算 | 合计 **4,447,745**（约 **4.45M**），< 5M |
| 可开关 | `use_uncertainty` / FiLM checkpoint 环境变量控制 |
| 初始不破坏基线 | FiLM **identity init**（γ→1, β→0）；`init_weights` **跳过** FiLM 参数 |

**Score-Gated FiLM（代码已完成，checkpoint 待重训）**

```text
γ = 1 + s · (γ_raw − 1)      β = s · β_raw
s → 0  ⇒  恒等调制（正常场景应尽量不影响基线）
```

## 2.2 UQEstimator

| 组件 | 说明 |
|------|------|
| 输入 | patch tokens `[B, 6, 1600, 1024]` + 5 维统计特征（方差、熵、跨视角相似度等） |
| 结构 | Linear 降维 → 2 层 TransformerDecoder（16 learnable queries）→ pool；统计分支 5→64；融合后 512→256 |
| 输出 | `score`（Sigmoid）、`embedding`（LayerNorm，供 FiLM） |
| 参数量 | **2,210,817** |

**训练损失**

```text
L = L_MSE + 0.1 · L_cal + 0.5 · L_rank
```

- **MSE**：拟合伪标签  
- **Calibration**：防止 batch 内 score 方差塌缩  
- **Ranking**：pairwise margin，恶劣样本 score > 正常样本  

**训练配置要点**：默认 **20 epoch**、batch ≥ 4（单样本 batch 会使 calibration 中 std 无定义）；可选 `preload` + FastTensorLoader；patch **子采样 256**/view 以省显存。

## 2.3 伪标签 v1 → v2 → v3（决策路径）

无人工「不确定性」真值，标签由 patch 统计构造，经历三轮迭代：

| 版本 | 要点 | AUROC（相对 weather adverse） | 状态 |
|------|------|------------------------------|------|
| **v1** | gradient 恒 0.5 + 弱 entropy；min-max 校准 | **0.621** | 已废弃 |
| **v2** | 按 Cohen's d 重加权：max_mean 50% + cosim 35% + entropy 15%；百分位校准 | 标签空间内 **0.993**；与 eval **不对齐时 0.601** | 备份保留 |
| **v3** | 增加 `--scene_type_map`（**weather-based**），与开环 eval 一致 | **0.954** | **当前使用** |

**v2 → v3 关键教训**

- v2 的 `scene_type` 来自场景类型（如 Accident→adverse），而 `eval_openloop` 用 **Weather ID 0–3** 定义 Normal。  
- **2,481 / 12,806（19.4%）** 样本分类不一致，导致 v2 高 AUROC **不能**直接用于对外汇报。  
- v3 修正后 AUROC 为 **0.954**（`results/eval_openloop_v3.json`），才是与实验协议一致的数字。

**v2 相对 v1 的组件变化（摘要）**

| 特征 | Cohen's d（经验） | v1 权重 | v2 权重 |
|------|-------------------|---------|---------|
| max_mean | 强（~1.07） | 0% | **50%** |
| cross-view cosim | 中（~0.53） | 40% | 35% |
| entropy | 弱（~0.06） | 30% | 15% |
| gradient（无图时常数） | — | 30% | **0%** |

产出文件：`data/labels/uq_labels.pt`（v3）、`uq_labels_v2.pt`、`uq_labels_v1_backup.pt`、`weather_scene_type_map.pt`。

## 2.4 FiLM 双层注入

| 层 | 作用位置 | 参数量 | 直觉 |
|----|----------|--------|------|
| **L1** | QT-Former detection queries | 131,584 | 场景理解层「感知变差」 |
| **L2** | VAE 前 `current_states` | 2,105,344 | 轨迹分布更保守 |

**训练模式（环境变量）**

| 模式 | 配置 |
|------|------|
| 仅 L1 | 默认 |
| 仅 L2 | `USE_FILM_L2_ONLY=1` |
| L1+L2 | `USE_FILM_L1L2=1` |

**已保存 checkpoint（`checkpoints/film/`）**

| 文件 | 说明 |
|------|------|
| `best_l1.pt` | 仅 L1 |
| `best_l2.pt` | 仅 L2 |
| `best_l1l2.pt` | L1+L2，L2 轨迹损失 |
| `best_l1l2_col.pt` | 旧版碰撞感知 |
| **`best_l1l2_col_v3.pt`** | **当前主结果**：L1+L2 + 碰撞 hinge，λ_col=0.5 |

**碰撞感知项（v3）**

```text
L_FiLM = L_plan + λ_col · E[ ReLU(m − d_min) · s_UQ ]     m = 4 m,  λ_col = 0.5
```

高 UQ 帧上更强烈惩罚「离障碍物过近」的预测，促使恶劣场景保守；详见第四章与第六章「保守捷径」讨论。

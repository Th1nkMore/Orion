## 1.1 项目定位

### 正文

**ORION**（ICCV 2025）是 VLM 驱动的端到端自动驾驶：多视角图像经 EVAViT、QT-Former、Qwen VLM、VAE，直接输出未来轨迹。在标准（晴/多云白天）条件下表现强劲，但在**雨、雾、夜间**等感知退化条件下，容易出现两类问题：

1. **行为仍偏激进**——模型缺少「当前看不清楚」的自我感知；  
2. **常用开环 L2 指标掩盖风险**——恶劣场景 L2 可能更低，碰撞率却高得多（见 §1.2）。

**UQ-ORION** 的定位：在**冻结** ORION 主干（约 1B 参数、36GB 权重）的前提下，增加约 **4.45M** 可训练参数的**侧信道**：

- 用 **UQEstimator** 从 patch tokens 输出「感知有多差」（标量 score + 条件向量）；  
- 用 **FiLM** 在 QT-Former 与 VAE 两处做条件调制，使高不确定时规划更保守。

本阶段**不**追求刷榜全数据集 L2，而是回答：**能否监测退化？能否改变行为？代价是什么？能否空间化？**

**ORION 主流程（本阶段均冻结）**

```text
多视角图像 → EVAViT → patch tokens [6 × 1600 × 1024]
              → QT-Former → BEV / 检测 query → VLM 记忆
              → Qwen VLM → 规划相关特征
              → VAE + 多模态 anchor → 未来 3s 轨迹
```

## 1.2 核心发现：L2 精度与安全风险脱节

### 正文

在 Bench2Drive（B2D）**验证集 12,806 帧**上，对 **ORION 基线**（无 FiLM）做**开环**评估：每帧独立预测 3s 轨迹，与 GT 比较。按天气分为 **Normal**（Weather ID 0–3）与 **Adverse**（其余 19 种，见 §1.4）。

| 指标 | Normal（2,709 帧） | Adverse（10,097 帧） | Adverse / Normal |
|------|-------------------|----------------------|------------------|
| **L2@3s（m）** | **2.38** | **1.78** | **0.75×**（恶劣更低） |
| Col@1s | 0.02% | 1.78% | ≈ 89× |
| **Col@3s** | **0.01%** | **1.61%** | **≈ 161×** |

**三条解读（写入汇报正文，也作为 PPT 旁白）**

1. **L2 更低 ≠ 开得更安全**：恶劣场景常伴随更低车速、更短位移、更「好拟合」的局部轨迹，L2 在统计上会被系统性压低。  
2. **Col@3s 才是安全向信号**：基于 GT occupancy 与预测轨迹的几何碰撞检测，恶劣场景高出约 **两个数量级**。  
3. **项目立项逻辑**：需要 **UQ（感知质量）** + **碰撞/回放（行为安全）**，不能只看 L2。

### 1.2.1 B2D 榜单口径：开环 L2 与闭环 DS 可以「倒挂」

Bench2Drive / ORION 论文主表同时报告 **开环 Avg. L2** 与 **闭环 DS / SR**。其中：

- **Avg. L2**：在 2 Hz 下，对未来 **2 s** 轨迹点的平均位移误差（米）——**不是** L2@3s，也**不是** nuScenes 附录里的 0.55 m@3s。
- **闭环主榜**：**Driving Score (DS)**、Success Rate；B2D 作者亦指出，开环 L2 更适合看收敛，**不宜单独用来排名闭环能力**。

**文献中的跨方法对照（B2D base set，ORION 论文 Table 1）**

| 方法 | 开环 Avg. L2 ↓ | 闭环 DS ↑ | 闭环 SR ↑ |
|------|----------------|-----------|-----------|
| **ORION（官方）** | **0.68** | **77.74** | **54.62%** |
| UniAD-Base | **0.73** | 45.81 | 16.36% |
| VAD | 0.91 | 42.35 | 15.00% |

**读表要点（组内汇报可照念）**

1. **UniAD 的 Avg. L2（0.73）仅略高于 ORION（0.68）**，但 **DS 仅 45.81，远低于 ORION 的 77.74**——这是 B2D 上最经典的例证：**开环 L2 略好或接近，并不保证闭环更好**。  
2. 因此，本项目在 §1.2 主表中强调 **Col@3s 的 161×**，并在后文用 **回放碰撞 / ADE** 讨论 FiLM，与 B2D 社区对「L2 不够」的判断一致。  
3. **我们自评的 ORION 基线**（`b2d_infos_val.pkl` **全量 12,806 帧**）与论文 Table 1（**50 clips** 开环子集）**不是同一评估集**，数字不宜逐字对齐论文。

**本仓库自评 ORION 基线（开环，无 FiLM，便于组内对照）**

| 指标 | All | Normal | Adverse | 与 B2D 榜单可比？ |
|------|-----|--------|---------|-------------------|
| **L2@2s**（≈ Avg. L2 口径） | **1.08** | 1.25 | 1.04 | 同一类指标，但 **全集 ≠ 论文 50 clips** |
| L2@3s | 1.91 | 2.38 | 1.78 | 仅用于 §1.2 天气分层叙事，**勿与 0.68 比** |
| Col@3s | 1.27% | 0.01% | 1.61% | 自研全集统计，非 Table 1 官方列 |

> 自评数据：`results/eval_openloop_full_summary.json`。论文开环/闭环：`ORION` Table 1（Bench2Drive base set）。

**组内可能被问**：「0.01% 和 1.61% 绝对值都很低？」  
→ 答：关注 **相对倍数与分层趋势**；绝对率依赖 B2D 栅格与开环定义，但 **161× 的分层差异** 足以说明「同一模型、不同天气，风险结构完全不同」。

**组内可能被问**：「我们 L2@2s=1.08，比论文 ORION 0.68 差很多？」  
→ 答：① 比的是 **L2@3s=2.38 vs 0.68** 时口径错了；② 应对齐 **L2@2s**；③ 论文是 **50 clips**，我们是 **12806 帧全集**；④ 即便开环 L2 偏高，**闭环/安全仍要看 DS、Col、回放**，UniAD 已证明 **L2 低 ≠ 闭环好**。

## 1.5 评估体系（本报告用到的两类）

### 正文

后文数字分两类评估；**组内汇报必须先立规矩**，否则「闭环碰撞降了」会被理解成 CARLA 仿真成绩。

### 开环（`eval_openloop`）

| 项 | 内容 |
|----|------|
| 做法 | 12,806 帧**逐帧独立**推理，预测 3s 轨迹 vs 同帧 GT |
| 指标 | L2@1s/2s/3s；Col@1s/2s/3s |
| 用途 | 第一章悖论表；第三章 UQ vs weather（AUROC）；开环分层 L2/Col |
| 局限 | 无状态累积；**不能**代替真实驾驶安全 |

### 回放式闭环（`eval_closedloop_replay`）

| 项 | 内容 |
|----|------|
| 做法 | **50** 条预录路线逐帧推理，对比 GT 控制与轨迹 |
| 构成 | Normal **11** + Adverse **39** |
| 指标 | ADE@3s、Col@3s、Throttle/Brake/Steer MAE、均速、UQ |
| 用途 | 第四章 Baseline vs FiLM；「保守捷径」讨论 |
| 局限 | **无仿真反馈**；ego 始终 GT 位姿；他车不响应自车 |

### 与真实 CARLA 闭环

| 维度 | 回放式（本报告） | 真实 CARLA |
|------|------------------|------------|
| 反馈 | 无 | 有 |
| 位姿 | GT | 漂移累积 |
| 碰撞 | 栅格几何 | 物理引擎 |
| 用途 | 快速对比、消融 | Phase 2 / 后续验证 |

**表述口径（建议背熟一句）**  
「回放结果用于看 **Baseline 与 FiLM 的相对变化与分层趋势**，不是对外宣称的真实道路碰撞率。」
